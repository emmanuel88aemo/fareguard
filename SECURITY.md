# Security policy

## Reporting a vulnerability

Please report security problems privately through
[GitHub security advisories](https://github.com/emmanuel88aemo/fareguard/security/advisories/new).
Do not open a public issue for them.

Include what you tried, what happened and what you expected. Reports about a way to make the
agent break one of its documented rules are welcome.

## Scope

This repository is a demonstration agent. It is deployed only in its author's AWS account and
holds no third-party data.

## Secrets

No credentials, tokens or account identifiers belong in this repository. If you find one,
report it as above.
